When creating the project folder for this assignment, I followed from the reading to include separate folders for data, scripts, and outputs as well as a docs folder. When I was working over the summer on the machine learning project for my internship, documentation was extremely important. Because of this, I wanted to make sure I have a folder set as an organized place to put these documents that is separate from the data/scripts, so I added the docs folder in addition to the standard folders for data, scripts, and output. Having these four folders ensures that everything is separate and can be updated independently. From the lesson and reading it is really important that outputs need to be replaceable and everything else well documented.

Finally, the importance of using documented code in computational research tasks is essentially so others can repeat the procedure and hopefully get the same results. In my internship, it was important for me to document code so others who I handed off the project to could know my process to get to where I left off in the project and see the results from the same point. Additionally, from the reading, reproducibility is hugely important in scientific research, yet can sometimes get overlooked in computer-based projects. Projects can be then susceptible to small errors that result in different outputs or render the projects unreproducible. By documenting code, changes, and processes, even if there are mistakes, others and yourself can know the process that got to that point and can hopefully adjust without becoming completely lost or introducing new errors.
